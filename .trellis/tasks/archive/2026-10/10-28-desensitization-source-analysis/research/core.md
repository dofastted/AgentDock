# 脱敏核心源码研究（规划依据）

## 边界与入口

- 核心 API：`redact.go:37-73` 的 Options，`:681-703` 的 Mask/Preview，`json.go:383-448` 的 MaskJSON，`json.go:477-496` 的 RestoreJSON，`redact.go:1175-1228` 的 Restore，`writer.go:9-42` 的流式 Writer。
- 生产核心除标准库只直接需要 publicsuffix（`redact.go:19-35`）；模型接口是 byte offset 的 Found 和回调 Model（`model.go:16-25`），不是算法核心直接依赖宿主模型。

## 已核对机制

1. 规则引擎：`redact.go:136-182` 内置密钥、私钥、JWT、赋值/连接串、个人信息等规则，带 marker 预筛和上下文/校验。用户词可区分大小写或 Unicode 折叠（`:728-747`）。用户规则在 Secrets 开关下先于内置规则加入（`:748-753`）；模型候选和已知值后加入（`:816-827`）。
2. 优先级不是一句“模型优先”：`redact.go:1091-1147` 统一排除既有占位符/保形值，按起点升序、同起点长度降序稳定排序，重叠取最先；完全相同区间保留先加入者。Allow 大小写不敏感整值比较（`:1150-1157`）；Warn 原样发送且只报告，不记入替换数量；Block 替换并报告，真正拦截由宿主负责。
3. 稳定占位符：`redact.go:490-566` 用 HMAC-SHA256(kind+NUL+value)，Base32 小写前 8 字符。原值映射是进程内 `map[string]string`，RWMutex 保护；`SetKeyPath` 可让 32-byte 密钥跨重启保存，原值与密钥必须区分。
4. 内存上界：`redact.go:498-500,569-584` 达 200000 项删除一半并重建 known 索引。注意注释写 oldest，但实际是 Go map 遍历删除，不保证最老；不能在文档照抄 LRU/精确 FIFO。
5. 已知值与缓存：`known.go:29` 最短 8 bytes；`:215-277` 为发送文本缓存 known spans，以文本和 Secrets/Personal/Kinds 的哈希为键，两代每代 65536 项，避免新发现的已知值回头改变已发送前缀。不能把“已知值任何地方全遮”不加条件地推广到重复发送文本。
6. JSON：`json.go:368-448` 对可处理字符串遍历、模型一次聚合请求文本；非 JSON 回退纯文本；签名对象先跳过规则，再把本次已替换值及已知秘密重遮回模型签名时的形式。`:40-60` 区分协议 ID、工具定义和参数；`redact.go:705-727,830-923` 处理工具参数中嵌套 JSON 转义边界，不对 JSON 全树盲目替换。
7. 保形：`shape.go:12-36,85-187` 用同一密钥派生假值，保留前缀/分隔符/长度/字符类别。当前最低长度 8、至少 6 个生成字符，不是现有部分文档写的 16。不合适的值回退占位符；保形结果碰撞已有不同值时也回退。
8. 模型：`model.go:27-44,51-95,109-161` 只接入支持的标签，在统一开关下合并并用边界、格式和上下文过滤误报。`masking/masking.go:42-53` 模型失败会 panic，再由 gwmw.Safely 转成失败关闭错误，不是悄悄仅用规则继续。
9. 还原：`redact.go:1171-1267` 可识别大小写、空格、缺括号变体，但只还原进程当前记忆里的占位符；工具参数按 escaped 重新 JSON 转义。`writer.go:60-72,89-127` 对 SSE 按事件处理，对普通 body 缓冲到 Finish；压缩且非 identity 的内容原样转发，不做该层还原。`:13-17` 描述的 pending tail 机制支持占位符跨 delta；最终细节与多协议边界在执行阶段用现有测试与 smoke 验证。

## 不能夸大的保证

- 8 个 Base32 字符是 40-bit 截断标签，不是加密密文；普通 placeholder 路径 `redact.go:556-566` 未见碰撞消歧，不能写绝对无碰撞；这里是源码推导风险，并非已复现碰撞。
- `redact.go:530-542` 忽略随机读取及持久化写入错误；是否符合宿主预期需如实说明，不能把保存密钥失败误写成一定阻断请求。
- 映射被淘汰/重启后未由请求补回的值无法还原。预览不保留映射，但可能初始化标签密钥（`redact.go:550-553,687-703`）。
- 原值仅存内存不等于本机 UI 永远无法取到原值；宿主值查询 API 是专门能力，须单列信任边界。
- 本文是静态源码确认，不包含运行通过声明。
